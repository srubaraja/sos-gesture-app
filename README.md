# 🆘 Emergency SOS Gesture Recognition

A simple AI that watches your camera and detects SOS hand signals!

## How It Works 🤖

1. **Camera Watches**: Your webcam looks for hands
2. **AI Understands**: Special computer brain recognizes hand shapes
3. **SOS Detection**: Looks for pattern: ✊ ✋ ✊ ✋ ✊ ✋ (fist/open hand)
4. **Alert**: Turns red and makes noise when SOS detected!

## Setup Instructions 🛠️

### Easy Way (Just View):
1. Go to Settings → Pages
2. Select "GitHub Pages" source: "main branch"
3. Wait 5 minutes, then visit your website!

### Run Locally:
1. Download all files
2. Open `index.html` in web browser
3. Allow camera access when asked

## How to Make SOS Signal ✋

Quickly alternate between:
- **Fist** ✊ (all fingers curled)
- **Open hand** ✋ (fingers spread out)

Do this pattern: Fist → Open → Fist → Open → Fist → Open
